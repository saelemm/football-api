# football-adapter-persistence-jpa

Adapter de persistence pour les ports du domaine, base sur Spring Data JPA.

## Contenu

- Entites JPA (`TeamJpa`, `PlayerJpa`, `TransferJpa`)
- Repositories Spring Data
- Adapters des ports (`TeamRepositoryAdapter`, `PlayerRepositoryAdapter`, `TransferRepositoryAdapter`)
- Tests d'integration JPA avec Testcontainers PostgreSQL

## Dependance principale

- `football-domain`
